# Uso dos logotipos

- Fundo claro: axis_logo_primary.svg.
- Fundo navy/escuro: axis_logo_dark.svg ou axis_logo_white.svg.
- Avatar e aplicativo: axis_app_icon.svg.
- Espaços compactos: axis_symbol.svg.
- Impressão a uma cor: versões monochrome.

Não alterar proporções, cores, tipografia ou espaçamento entre símbolo e nome.
